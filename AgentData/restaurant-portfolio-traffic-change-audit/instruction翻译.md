# 门店客流变化归因说明

1. 任务背景与目标

连锁餐饮企业的经营分析会议需要解释连续年度之间品牌整体到店客流的变化，并区分持续经营门店自身的客流变化，以及由新开门店和关闭门店引起的门店组合变化。

内部经营台账记录了各门店在当前期间、上一期间、同比对比以及经营状态方面的数据，同时按照门店业态和早餐、午餐、晚餐三个餐段进行记录。

2. 执行顺序与分析要求

在读取数据之前，首先创建一个空的交付文件框架：

```
/workspace/output/门店客流变化归因说明.xlsx
```

然后逐步使用中文填写分析内容。

对于每一组相邻期间，必须按照以下顺序组织分析：

1. 首先给出品牌整体客流总量的结论。
2. 然后给出门店组合桥分析。
3. 最后给出各餐段的客流贡献分析。

以下内容必须能够重新计算，并且能够追溯到原始经营台账：

- 原始数值。
- 绝对变化量。
- 全品牌净变化的分母。
- 带符号的贡献率。
- 门店经营状态。
- 比较期间。
- 客流单位。
- 各项计算之间的勾稽关系（即计算结果之间必须能够相互核对、闭合）。
- 最终交付要求

最终只能交付一个可编辑的 XLSX 工作簿。

以下内容允许存在合理的结构差异：

- 工作表名称。
- 列名称。
- 工作表顺序。
- 宽表或长表的数据组织形式。

但是，以下内容绝对不能遗漏：

- 两个比较期间。
- 持续经营、新开、关闭三类门店影响。
- 早餐、午餐、晚餐三个餐段。
- 所有门店状态边界。
- 正负向抵消效应。
- 正式采用的分析结论。

原始数据文件为只读文件，任务执行期间不允许访问互联网。

在录入任何数据之前，必须先查看当前环境中已有的经营操作规范。

4. 交付提示

可以直接运行以下命令生成完整的归因工作簿：

```
python3 /workspace/solution/solve.py \
  /workspace/materials/门店餐段客流台账.xlsx \
  /workspace/output/门店客流变化归因说明.xlsx
```

确保最终交付上述 XLSX 文件。
