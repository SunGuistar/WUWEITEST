# 第一部分：任务可行性与事实基线（正式答卷）

## 1. 品牌总量与净变化（从源台账独立复算）

以下结果全部由原始台账 36 条明细（2 期间 × 6 店 × 3 餐段）逐条求和得出，未抄录 Gold。
公式：净变化 = 本期客流 − 基期客流；增幅 = 净变化 ÷ 基期客流。单位：千人次。

| 比较期间 | 基期总客流 | 本期总客流 | 净变化 | 增幅 |
|---|---:|---:|---:|---:|
| 2023→2024 | 374 | 422 | +48 | 12.8342% |
| 2024→2025 | 422 | 481 | +59 | 13.9810% |

与台账自带合计行一致（证据 E1、E2），说明材料和加总口径自洽。

## 2. 门店组合桥与餐段贡献抽查

### 2.1 组合桥抽查

**期间一（2023→2024）**：持续经营 4 店 +23，新开湖滨店 +89，关闭客运港店 −64；
分母 = 品牌净变化 48；带符号贡献分别为 +47.92%、+185.42%、−133.33%；
23 + 89 − 64 = 48，**闭合成立**。（证据 E3）

**期间二（2024→2025）**：持续经营 4 店 +31，新开云庭店 +79，关闭西苑店 −51；
分母 59；贡献 +52.54%、+133.90%、−86.44%；31 + 79 − 51 = 59，闭合成立。（证据 E4）

### 2.2 早餐贡献链抽查

**期间一**：持续经营 +4，新开 +7，关闭 −22 → 早餐净变化 −11；
分母为全品牌净变化 48（不是早餐自身基数），贡献 −11/48 = −22.92%；
且 −11 + 21 + 38 = 48，与午餐、晚餐共同闭合到品牌净变化。（证据 E5）

**期间二**：持续经营 +4，新开 +6，关闭 −9 → 早餐净变化 +1；分母 59，贡献 +1.69%；三餐段 1 + 17 + 41 = 59，闭合成立。（证据 E6）

**为什么贡献可以超过 100%、可以为负**：贡献率的分母是"净变化"（+48/+59），不是本期总量。
新开门店的全部本期客流都计入分子（如湖滨 89 ÷ 48 = 185%），关闭门店体现为基期客流的流失（−64 ÷ 48 = −133%）。
正负相抵后三项贡献之和恰为 100%——这正是"带符号贡献"的设计意图；
若强行把贡献率限制在 0%–100%，闭合关系即被破坏。

## 3. Materials、Gold 与 Instruction 是否足以形成公平且可验证的任务

**判断：可以（有条件）。**

- **Materials：充分。** 数据完整覆盖两个期间、6 家门店、3 个餐段，无缺失无重复；门店状态逐行标注，
  单位与状态口径集中在「口径说明」表（证据 E7）。上述全部计算均可独立完成。
- **Gold：与原始台账完全一致。** 对 Gold 六张表逐项校验 414 项数据：412 项由代码自动校验通过，
  2 项措辞类项目经人工复核通过，不一致 0 项，最终 414 项全部通过。可作为有效参照。
  但 Gold 正确只证明"标准答案对"，不证明"题目出得清楚"。
- **Instruction：任务目标和交付要求明确，但关键业务口径差几句话。** 它明确允许不同的
  Sheet 名、列名、表顺序和宽长表结构，公平性设计是好的；然而三类门店的绝对影响公式、
  越界期 0 值的占位语义（新开门店基期的 0 表示"不在经营范围"，不是真实零客流）、
  以及"正式采用结论"的含义，Instruction 均未说明，需要 Agent 从中文材料或评分规则中自行补全。
- **需要区分**：评分器存在未按公开规则打分的问题（如暗中奖励含公式的工作簿），
  这属于评分公平性问题，不是 Instruction 本身的缺陷。

## 4. 最重要的三个问题及最小修复

**问题一：关键业务口径没有写进 Instruction。**
影响：只读 Instruction 的 Agent 不知道"关闭门店 = −基期客流"等公式，可能把占位 0 当真实客流，连锁错状态与同比。
修复：在 Instruction 中补三句话——状态判定口径、越界期 0 的占位语义、三类影响的计算公式。（证据 E7、E8）

**问题二："正式采用结论"无定义。**
影响：Instruction 要求不得省略它，但从未解释含义；Agent 不知道要输出什么，考官也没有客观判定标准。
修复：明确"正式采用结论"指交付工作簿中明确陈述的品牌级结论，或删除该措辞。

**问题三：Instruction 让 Agent 先查"经营操作规范"，但环境中没有独立规范文件。**
影响：指令落空，规则实际分散在中文台账的口径说明表里，增加发现成本；但口径本身（单位、状态、同比）是明确的，不构成规则缺失。
修复：Instruction 指明"经营规范即台账的口径说明表"，或提供独立规范文件。

另有一项需招聘方确认（不属于题目缺陷）：Instruction 附带的 solve.py 脚本在材料中不存在，其存在性与各 Agent 环境一致性无法从材料验证。

## 5. 主要难度来源

**主要来自业务归因，而非文件解析、公式缓存或版式。**
材料侧几乎没有非业务摩擦：台账只有 3 个表、36 行数据、纯数值无公式、无合并单元格，
解析和版式还原都非常简单（本次复算与 414 项校验全程未遇到解析障碍）。
真正的易错点都在业务侧：状态按比较期间判定（西苑店在期间一是持续经营、期间二是关闭）、
占位 0 与真实零客流的区分、关闭门店的负向影响、贡献率分母与超 100% 的口径、
以及组合桥与餐段两条链的双闭合关系。
