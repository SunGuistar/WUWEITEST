# probe-02 审计报告（受控测试样本，非真实模型运行）

## 1. 基本信息

单表「审查样本」A1:N9，仅覆盖期间一（2023→2024）的全品牌/组合桥/餐段层级 + 1 行控制行；**无任何 2024→2025 数据行**。

## 2. 核心缺陷

**覆盖不完整：遗漏整个第二比较期间（2024→2025）。**

- 任务要求每个相邻期间都给出品牌结论、组合桥与餐段归因（Instruction 第 1 段）；probe-02 只完成期间一。
- 样本自身已声明：N9="仅完成第一比较期间"——这是明示的"部分完成"样本。
- 与 probe-01 结构相同但缺陷本质不同：probe-01 是**数值口径错误**（分母错），probe-02 是**范围遗漏**（无错误数值，缺一半交付）。

## 3. 具体业务影响

- 缺失期间二的全部内容：品牌总量 422→481、净变化 +59、组合桥（+31/+79/−51）、三餐段贡献（+1/+17/+41）、期间二闭合。
- 业务后果：决策层看不到 2025 年的任何归因信息；不完整交付不能支撑"两个相邻期间"的复盘要求。
- 已覆盖的期间一内容无任何业务影响问题（见下）。

## 4. 正确内容与错误内容

**正确**：期间一 7 行数据全部正确——品牌 374→422/净变化 48/贡献 1.0；组合桥 23/89/−64，贡献 47.92%/185.42%/−133.33%（J=48 分母正确，与 probe-01 形成鲜明对照）；餐段 −11/21/38，贡献 −22.92%/43.75%/79.17%；第 9 行控制行勾稽关系 23+89−64=48 成立。
**错误**：无数值错误；缺陷是**遗漏期间二**（覆盖性错误，不是计算错误）。

## 5. 应保留的信用

- 期间一全部链条应全额得分：原值（R2 期间一部分）、状态边界基础、组合桥 3 链与餐段 3 链的绝对变化+贡献叶子（R4/R5 期间一）、期间一闭合（R6）、期间一结论（R7）。
- "部分完成但已完成部分正确"应得相应比例信用，不能因遗漏期间二而清零期间一。

## 6. 应失去的信用

- 期间二全部维度的信用：R4/R5 期间二各链、R6 期间二闭合、R7 期间二结论、R2 期间二原值。
- 不编造具体分值；按 Rubric 的"跨链平均"结构，缺失链自然得 0 即实现比例化。

## 7. 错误根因与传播范围

单一根因：**交付范围不完整（期间二遗漏）**。受影响位置 = 期间二全部评分维度；无下游数值传播（因为没有期间二数据可污染）。
注意与 probe-01 区分：probe-01 的根因污染了期间一的所有下游结论；probe-02 的期间一干净，两者**不应得到相同的评分处理**。

## 8. 多个独立错误的处理

仅一个根因（遗漏），无并存独立错误。

## 9. 当前 Rubric / Scorer 的误判风险

- **已确认（规则层面）**：Rubric 各维度按两期间的链平均/逐项计分，缺失期间二自然失分——方向正确；且"完成一半但全对"与"全完成但有错"在得分上应可区分（前者期间一满格、后者全链打折）。
- **潜在误判一（偏高风险）**：样本自带"勾稽通过"控制行（N9）；Rubric 明确"只写 reconciled 不展示两侧数值不得分"，本样本有数值支撑，无此问题——但提醒我们：若 scorer 语义层把"勾稽通过"字样当作完成证据而忽略期间二缺失，会高估。
- **潜在误判二（偏低风险）**：若 scorer 把"工作簿不完整"视为整体 artifact 缺陷（类似 0 分条款"missing"），可能错误清零期间一的正确信用。
- **待 4.4 确认**：0 分条款"artifact is missing / unreadable / substantively empty"的判定是否会被部分完成触发。

期间一全链得分；期间二全维度失分；总评=部分完成的比例化信用。与 probe-01 不同处理：probe-01 期间一贡献率失分、期间二得分；probe-02 期间一得分、期间二失分——两者总分可能接近，但**失分结构完全不同**，评分体系应能表达这种差异（现有叶子结构可以）。
