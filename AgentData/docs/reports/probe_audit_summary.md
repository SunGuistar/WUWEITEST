## 横向比较结论

### 1. 三个 Probe 分别测试什么类型的问题（按实际内容归纳，非预设）

- **probe-01 → 计算口径错误型**：一个上游分母错误，下游贡献率/结论/闭合全部污染。考验评分体系能否识别"绝对影响全对、贡献率全错"的部分正确结构，并按根因去重。
- **probe-02 → 部分完成/遗漏型**：已完成部分全对，缺一半交付。考验评分体系能否比例化给分（对的一半得分、缺的一半不得分），而不是全有或全无。
- **probe-03 → 表面合规无证据型**：结构外壳齐全、自证到位，但零可验证内容。考验评分体系能否拒绝"形式与自证"，识别证据缺失。

三者构成对评分体系的正交压力：错（01）、缺（02）、空（03）。

### 2. 哪个存在实质性业务错误

仅 probe-01（期间一贡献率与结论错误且闭合破坏）。probe-02 无数值错误（遗漏非计算错误）；probe-03 无数值可判（证据缺失非计算错误）。

### 3. 哪个属于证据不足/可验证性不足

probe-03（完全无证据）。probe-02 对已覆盖部分证据充分；probe-01 证据（来源列）存在但对期间一结论形成反证。

### 4. 正确部分应获得的信用

- probe-01：原始值+绝对影响+期间二全链（约一半以上内容正确）。
- probe-02：期间一全链（约一半内容正确且全对）。
- probe-03：无可保留业务信用。
→ 三个样本的合理得分应明显区分：probe-02 ≈ probe-01 > probe-03（01 与 02 总分可能接近但失分结构相反），probe-03 趋近 0 并触发扣分。

### 5. 当前评分规则对三者是否可能产生不同类型的误判

是：01 的风险是"重复扣分/根因不去重"；02 的风险是"整体清零或自证高估"两个方向；03 的风险是"语义层被自证与重复结构欺骗"。三者误判机制各不相同，恰说明单一评分策略难以同时公平处理"错、缺、空"三类失效。

### 6. 是否存在结构不同但业务质量相同的情况

probe-01 与 probe-02 结构完全相同但业务质量不同（01 有错、02 无错但缺）——证明**同结构不可推同质量**；probe-03 与 rollout 们结构不同且质量天差地别——证明**结构差异必须与内容证据分开评判**。两者共同支撑 Instruction"结构宽容"原则的合理性。

## 移交 4.4–4.5 的待验证清单

1. Scorer 分母绑定：是否真按"品牌净变化"比对贡献率（决定 probe-01 能否被抓）。
2. 0 分条款"substantively empty / missing"的触发条件（决定 probe-02 期间一是否会被误清零）。
3. 语义层对"勾稽通过"自证的处理（probe-02/03 的高估风险）。
4. R9 公式启发式对常数/伪公式的反应（probe-03）。
5. 重复内容（probe-03 的 20 行复制）是否被当作丰富度。
