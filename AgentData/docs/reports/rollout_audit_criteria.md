## 2. 检查链 A：餐段贡献核验公式

对每份 Rollout 的餐段贡献表，逐期间逐餐段核验：

1. **三类门店影响**：持续 = Σ持续门店(本期−基期)；新开 = Σ新开门店本期；关闭 = −Σ关闭门店基期。
   符号规则：新开为正，关闭必须为负（负号缺失即错误）。
2. **餐段净变化** = 本期餐段合计 − 基期餐段合计 = 三分量之和。
3. **贡献率分母**必须为该期间的**全品牌净变化**（48 或 59）。
   误用餐段自身基数、本期总量或持续门店口径均为错误。
4. **正负号**：净下降餐段（期间一早餐 −11）贡献必须为负。
5. **餐段级闭合**：持续 + 新开 + 关闭 = 餐段净变化。
6. **品牌级闭合**：早餐 + 午餐 + 晚餐 = 品牌净变化（±0）。

容忍规则：数值精确一致；比率按显示精度半单位容差（如 −22.92% 对 −22.9167% 可通过）；
千人次→人次等单位换算需全链一致并声明单位。结构、措辞、公式/静态值差异不构成错误。

## 3. 检查链 B：门店状态边界核验规则

对每份 Rollout 的状态信息（状态边界表或门店明细中的状态列），逐"期间×门店"核验：

1. **分类正确**：与对照值一致（上表 12 项）。
2. **占位零 vs 真实零**：新开门店基期、关闭门店本期在追溯/明细中应体现为"不在范围"
   （0 或空或"不适用"均可接受，视其自洽性），**不得**当作观测零客流参与同比或状态推导。
   判定依据：基期为 0 时常规同比公式 (本期−基期)/基期 的分母为零，**同比未定义，
   绝不能算出 −100%**。判定方法：检查 Rollout 是否对湖滨店(期间一基期)、客运港店(期间一本期)、
   云庭店(期间二基期)、西苑店(期间二本期)给出同比/增量解释；若把这些 0 当真实客流
   计算同比（如"−100%"）即为占位零误用。
3. **缺失 vs 零**：本材料台账无缺失单元格；若 Rollout 自行引入"缺失"说法，需与源台账核对。
4. **与原始台账一致**：状态标注须与台账 D 列经营状态吻合（证据：台账客流对比_2024/_2025 D4:D21）。
5. **传播检查**：发现状态错误后，必须追踪该错误是否污染餐段三分量（检查链 A）。
   例：若西苑店在期间二被误标为持续经营，其 −51 将从"关闭"分量移到"持续"分量，
   期间二晚餐持续分量应为 +15，误标后将变为 +15+(−18) 之外的错值——
   通过对照基线三分量即可定位传播范围。

## 4. 证据记录格式

每条证据必须包含：
`[证据编号] 文件/Sheet/单元格（或行列区域）→ 观察值 → 对照值（基线来源）→ 判断（一致/偏差）`。

每份 Rollout 至少 2 条具体证据（检查链 A、B 各至少 1 条）；
发现异常时沿异常扩大取样，每条新增证据沿用同一格式。

## 5. 错误分类与根因传播判断

对发现的每个偏差，按以下四类归类（同一证据只归一类）：

| 类别 | 判定标准 | 计分影响方式 |
|---|---|---|
| 合理差异 | 结构/措辞/精度/单位换算差异，数值等价 | 不算错误 |
| 局部错误 | 单一数据点或单链条错误，无同源复制 | 按该点/链影响评价 |
| 根因传播 | 同一上游错误（如状态误标、分母误用）导致多处下游数值连带错误 | 视为**一个**根因，不按错误个数重复计重，但评价时注明传播范围 |
| 独立错误 | 无共同上游的多个不同错误 | 分别评价 |

根因识别方法：比较偏差值与基线的差值模式——若多个偏差可由同一错误输入
（如某店状态翻转、某分母替换）一次性解释，则归为根因传播。

## 6. 当前分数合理性评价标准

先独立判断实际业务质量，再与当前分数比较，四档结论：

| 结论 | 判定标准 |
|---|---|
| 合理 | 分数与实际质量基本一致（重要链条全对≈高分；重要错误存在≈低分） |
| 偏高 | 存在重要业务错误（状态错、分母错、符号错、不闭合），分数未充分体现 |
| 偏低 | 实际质量较好（检查链 A、B 全对），却受到不合理扣分 |
| 暂无法判断 | 现有证据不足以判断质量或分数成因 |

说明：当前分数来自 current_scores.md（仅作待审对象）；本阶段不深入 Scorer
内部实现，若审计中观察到明显评分机制现象（如静态值被系统性低估），记录现象与
证据，留待阶段四处理，不在本阶段下结论。
