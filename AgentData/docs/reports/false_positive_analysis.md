# 4.5.2 三个 Probe 假阳性分析

> 纪律：probe 无实际评分记录、快照不可运行 Scorer——本报告所有结论为"源码级推演"，
> 区分【机制已确认】（源码直接支持）与【潜在风险】（需运行时验证）。
> 不编造 probe 实际得分。

## 1. probe-01（计算口径错误）——能否被抓 & 双向风险

| 检查项 | 结论 | 性质 |
|---|---|---|
| Scorer 能否识别期间一分母错误 | 程序化契约比对以期望值为基准：若 probe-01 的表被绑定，期间一贡献叶子会因与期望值（47.9167% 等）不符而失分 → **能识别**；若绑定失败则整表记 0（抓错方式） | 机制已确认（比对逻辑），绑定成败待运行时验证 |
| 能否识别传播结果（7 贡献率+6 结论+闭合） | 贡献率叶子随绑定逐链判定可覆盖；结论文字属 semantic units，快照缺失无法确认 | 部分机制确认，semantic 待确认 |
| 重复扣分风险 | R4 期间一 3 链 + R5 期间一 3 链的贡献叶子同源；结算层按叶子计，**同一根因跨 6 链被多次计零**；R6B 期间一亦受污染。相对 4.3 基准"一个根因扣一次"，存在重复惩罚结构 | 潜在风险（结构推导） |
| 绑定失败时是否错误保留信用 | 反向风险：若契约表未绑定，程序化层全部记 0——期间一错误贡献被抓，但**绝对影响等正确叶子也被连坐清零**（违反基准"保留绝对影响信用"） | 潜在风险 |
| 语义层被表面特征欺骗 | probe-01 结构完整、数值近似正确（绝对影响全对），若 semantic units 只读结论文字可能放过期间一错误表述 | 潜在风险（不可验证） |

**小结**：probe-01 主要检验"错误能否被识别"（程序化层大概率能）；其暴露的评分体系风险是**根因重复计零**与**绑定连坐**两个方向。

## 2. probe-02（部分完成）——比例化是否成立

| 检查项 | 结论 | 性质 |
|---|---|---|
| 能否区分部分完成与完全失败 | 能：工件有实质内容，0 分条款（missing/empty/unreadable）不触发（源码条件明确） | 机制已确认 |
| 正确部分能否保留信用 | 期间一各链独立计分，R4 期间一 3 链若绑定成功则得分；但 **R5/R6 绑定失败会把正确期间一也清零**（同 rollout-01/02 机制） | 机制已确认（绑定结构），probe 实物未运行 |
| 缺失部分是否失分 | 期间二链缺席自然记 0；由于结算只认 R4/R5/R6B/R6E/R9，声明权重的 R2/R7 期间二部分**不在结算中**——比例化"恰好"由链结构隐式实现，非显式设计 | 机制已确认 |
| 遗漏被识别前提下获高分的风险 | 低：缺席链记 0 直接压低总分；无机制给缺席内容加分 | 机制已确认 |
| 语义层风险 | "勾稽通过"控制行对程序化层无作用；semantic 是否被其误导不可验证 | 潜在风险 |

**小结**：probe-02 检验"部分完成是否被合理比例化"——程序化层方向正确（链级独立 + 缺席记零），
主要残余风险仍是绑定失败连坐正确的已完成部分。

## 3. probe-03（表面合规、零证据）——能否骗分

| 检查项 | 结论 | 性质 |
|---|---|---|
| 程序化层能否识别内容缺失 | 能：无数值 → 各契约表无绑定 → R4/R5/R6B/R6E 全 0；无门店/来源词 → R8=0 | 机制已确认 |
| R9 是否被常数 2 欺骗 | **不会**：R9 要求 `=` 开头字符串单元格，常数 2 不满足（4.4 已确认，此处不重复立为案例） | 已确认（排除项） |
| R9 是否被"公式形式主义"利用 | 若样本含任意 `=` 公式且与"贡献/总/分母"同行即得分；probe-03 本身无公式故 R9=0，但**该类启发式对"无意义公式"无免疫力** | 机制已确认（对其他样本构成潜在假阳性通道） |
| 语义层被"勾稽通过"+20 段复制欺骗 | 语义判定（semantic units）快照完全缺失，无法验证；若语义层按措辞给分，20 行自证可能获不合理正向分 | **潜在假阳性风险（本报告最高优先级的待确认项）** |
| 整体判定 | 程序化层：probe-03 趋零分，符合 4.3 基准；语义层：不可确认 | 程序化已确认 / 语义潜在 |

## 4. 假阳性认定汇总

| 案例 | 认定 |
|---|---|
| probe-03 经语义层获虚高分 | **潜在假阳性风险**（语义组件缺失，无法证实或排除） |
| probe-01 绑定失败导致错误贡献"连坐清零"式正确、或语义层放过错误结论 | 潜在（双向） |
| 任意含公式工件经 R9 无差别加分（与业务质量无关） | 机制已确认；构成对"静态值全对工件"的相对假阳性（形式主义通道） |
| probe-02 获不合理高分 | 不成立（缺席链记零机制明确） |

## 5. 与 4.3 基准的对照结论

程序化结算层在三个 probe 上的推演行为与 `probe_scoring_baseline.md` 的期望方向一致
（01 失分、02 比例化、03 趋零）；偏离风险集中在三处：根因重复计零（01）、绑定连坐（01/02）、
语义层自证欺骗（03，不可验证）。无 probe 实际评分记录，全部推演结论均不可替代实物送评验证。
