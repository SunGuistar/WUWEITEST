# probe-01 审计报告（受控测试样本，非真实模型运行）

## 1. 基本信息

单表「审查样本」A1:N15，覆盖两个期间的全品牌/组合桥/餐段三个层级，含来源列与"正式结论"列。

## 2. 核心缺陷

**期间一（2023→2024）的"采用分母"错用持续经营影响 23，替代品牌净变化 48。**

- 正确口径（Independent Baseline）：全品牌净变化 = 422 − 374 = **48**。
- probe-01 期间一全部 7 行 J 列 = **23**（即持续经营影响值）；期间二 J 列 = 59（正确）。
- 证据：probe-01!J2:J8 = 23，对照基线分母 48（fact_baseline.json）。

## 3. 具体业务影响

分母错误传播到期间一全部贡献率与正式结论，并破坏闭合：

| 位置 | 实际值（÷23） | 正确值（÷48） |
|---|---|---|
| K2 全品牌贡献 | 2.087 | 1.000 |
| K3 持续经营 | 1.000（N3"持续经营贡献100.0%"） | 0.4792（47.9%） |
| K4 新开（N4"新开贡献387.0%"） | 3.8696 | 1.8542（185.4%） |
| K5 关闭（N5"关闭贡献-278.3%"） | −2.7826 | −1.3333（−133.3%） |
| K6 早餐（N6"早餐贡献-47.8%"） | −0.4783 | −0.2292（−22.9%） |
| K7 午餐（N7"午餐贡献91.3%"） | 0.9130 | 0.4375（43.8%） |
| K8 晚餐（N8"晚餐贡献165.2%"） | 1.6522 | 0.7917（79.2%） |

- 期间一组合桥贡献和 = 1.0+3.8696−2.7826 = **2.087 ≠ 100%**，不闭合；
  餐段贡献和 = −0.4783+0.9130+1.6522 = **2.087 ≠ 100%**，不闭合。
- 业务后果：读结论的人会误以为"持续经营贡献了全部增长、新开贡献 387%"，品牌增长动因被完全扭曲。
- 期间二（第 9–15 行）分母 59、贡献率、结论全部正确。

## 4. 正确内容与错误内容

**正确**：两期间全部原始值（D/E 列）、三类影响绝对值（F/G/H 列）、绝对变化（I 列，48/23/89/−64/−11/21/38/59/31/79/−51/1/17/41 全对）、期间二全部贡献率与结论、单位、来源引用（M2/M9 指向台账合计行）。
**错误**：期间一 7 行贡献率（K2:K8）与 6 条结论文字（N3:N8），及由此导致的期间一闭合破坏。

## 5. 应保留的信用

- 全部原始数据与绝对影响（R2 类原值、R3 状态边界对应的基础数据）。
- 期间二完整链条（贡献率与结论正确）。
- 组合桥与餐段的绝对变化链（R4/R5 的"绝对变化"叶子全部应得分）。

## 6. 应失去的信用

- 期间一全部"带符号贡献"叶子（R4 期间一 3 链 + R5 期间一 3 链的贡献叶子）。
- 期间一基于错误贡献率的正式结论（R7 相关叶子）。
- 期间一闭合断言（R6 中贡献和=100% 的两个叶子）。
不自行编造具体分值；现有 Rubric 叶子结构足以定位失分项，无需重新定义标准。

## 7. 错误根因与传播范围

**单一根因：期间一分母取错（23 替代 48）。**
传播路径：J 列分母 → K 列 7 行贡献率 → N 列 6 条结论文字 → 期间一组合桥/餐段两层贡献和≠100%。
**去重要求：计为一个根因**；受影响位置为期间一贡献率 7 行 + 结论 6 条 + 闭合 2 项，但不得按 15 个表现重复扣分。

## 8. 多个独立错误的处理

本 Probe 仅一个根因，无独立并存错误。（期间二正确，不构成错误。）

## 9. 当前 Rubric / Scorer 的误判风险

- **已确认（规则层面）**：Rubric R4/R5 明确"分母 = 品牌净变化"并给出期望值（47.9167%、185.4167%、−22.9167% 等），程序化比对可精确识别本缺陷——规则能抓住。
- **潜在误判（需按根因去重）**：若评分实现把 7 行贡献率当 7 个独立错误累计扣分，会夸大缺陷严重度；按 Rubric 的 min-叶子结构本应每链独立计，但同属一个分母根因，合理处理应在该根因范围内评价。
- **待 4.4 确认**：Scorer 的实际分母绑定逻辑是否以 Gold 期望值比对（能抓）还是接受任意分母自洽（会漏）。
