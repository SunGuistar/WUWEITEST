# 第二部分：5 份 Rollout 的风险导向抽查

### 2.1 审计方法

对五份 Rollout 采用统一的风险导向抽查标准，每份均检查两条业务链：

- **餐段贡献链：** 检查持续经营、新开、关闭三类门店的影响、餐段净变化、贡献率分母、正负号，以及餐段级和品牌级闭合关系。
- **门店状态边界：** 检查持续经营、新开、关闭的分类，特别关注占位零值与真实零值、缺失记录与零值的区别，以及状态分类对餐段贡献的影响。

核验以原始台账和独立计算基线为主要依据，Gold 作为交叉验证来源。五份文件分别独立检查，不因工作表名称、布局、公式或静态值的差异判定业务错误。

发现异常时，进一步检查其影响范围，区分局部错误、同一根因的重复传播和独立错误。

### 2.3 主要发现

**1. 五份 Rollout 的核心业务计算均正确。**

五份文件的六条餐段贡献链全部与独立计算基线一致。两个比较期间分别使用48和59作为全品牌净变化分母，持续经营、新开、关闭三类影响的符号正确，餐段级和品牌级闭合关系均成立。

门店状态方面，五份文件的12个期间与门店状态均符合原始台账，包括西苑店跨期间由持续经营转为关闭的状态变化。新开和关闭门店的占位零值均未被错误地用于常规同比计算，没有发现缺失值与零值混淆。

**2. 没有发现实质性业务错误或共同错误根因。**

五份 Rollout 在本次检查范围内均未发现业务计算错误，也没有发现同一错误在不同位置重复传播的情况。

rollout-04 将餐段净变化和贡献率集中展示在餐段首行，其他类别行显示0，但其实际分量计算和贡献率正确。这属于合理的表格表达差异，不应判定为业务错误。

**3. 当前评分与实际业务质量存在明显差异。**

五份 Rollout 在餐段贡献和门店状态两项核心业务检查中表现基本一致，但当前分数从0.294424到1.000000，最高与最低相差0.705576。

其中 rollout-01、02、04 的分数明显低于本次审计所体现的业务质量；rollout-03、05 的高分则与本次检查结果基本匹配。

这说明当前分数不能仅凭本次抽查结果得到充分解释，评分可能受到其他评分维度或表达形式的影响，需要在后续评分器审计中进一步确认。

需要说明，本次只检查了两条指定业务链，不能据此断言五份工作簿的所有评分维度均正确，也不能仅凭本次抽查完全确定总分偏低的具体原因。

### 2.4 本部分结论

五份 Rollout 均通过本次餐段贡献和门店状态边界检查，未发现实质性业务错误。不同工作簿在 Sheet 命名、布局和信息组织方式上的差异不影响其业务正确性。

但五份文件的当前分数差异远大于本次审计发现的实际质量差异，尤其是 rollout-01、02、04 的低分尚未得到业务错误证据的解释。

**因此，第三部分工作应进一步审查 Probe 和 Scorer，确认评分机制是否能够公平识别实际业务质量。**
