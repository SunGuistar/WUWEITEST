## 4. 分数问题的直接回答

1. **rollout-01 与 02 为何完全相同**：两者预存 completion 在所有加权项上完全一致（R4=R9=1、R5=R6B=R6E=0）→ 复算同分。唯二非加权差异（R6A 0 vs 1）不影响结算。
2. **rollout-03 为何接近满分**：R6B=R6E=1，比 01/02 多拿 65% 权重。
3. **rollout-04 为何只有 0.35**：R5=1（+5.56%）但 R6B=R6E=0——控制类表未绑定，65% 权重归零。
4. **rollout-05 为何满分**：五个加权项全 1。
5. **分数差异来自业务质量还是其他**：**不是业务质量**。第三阶段审计已逐格验证五份的餐段贡献与状态边界数值全部正确且闭合；而结算差完全由 R5/R6B/R6E 的 0/1 绑定差异解释 → 差异来源是**契约表绑定成败（布局敏感）+ 未公开的权重结构**，不是数值对错。
